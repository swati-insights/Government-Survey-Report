# 📊 E-Government Service Survey Report

## 📌 Project Overview

This project presents an **interactive dashboard** for analyzing citizen feedback on e-government services. The goal is to evaluate service performance, identify gaps, and support data-driven decision-making.

The dashboard is built using:

* **Microsoft Excel** → Data cleaning & preparation
* **Power BI** → Data visualization & dashboard creation

---

## 🎯 Objectives

* Analyze citizen satisfaction across different services
* Measure service performance using key metrics
* Identify trends in complaints, appeals, and resolution rates
* Provide actionable insights for improving government services

---

## 📂 Dataset Description

The dataset includes information such as:

* Application details (date, service type, district)
* Citizen demographics (age group, gender, income group)
* Service ratings (1–5 scale)
* Waiting time
* Resolution status
* Appeals and feedback data

---

## 📈 Key Metrics (KPIs)

* **Total Applications:** 350
* **Average Rating:** 3.08
* **Average Waiting Time:** 129.18 minutes
* **Resolved Percentage:** 24.00%
* **Appeal Percentage:** 47.14%
